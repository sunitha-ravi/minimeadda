# Coming Soon page

A responsive, white-background static landing page using only white, black, and red.

## Deploy to GitHub Pages
1. Extract these files into the root of your GitHub repository.
2. Make sure `index.html` and the `assets/` folder are in the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (usually `main`) and folder **/(root)**, then Save.

No build step or framework is required.
